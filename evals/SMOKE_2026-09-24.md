# v0.01 smoke evidence — 2026-09-24

This records limited checks, not a claim that Bodhi works for a new person over time.

- **CLI and optional vault:** `python3 -m unittest discover -s tests -v` passed 5 of 5 on this Mac. The tests initialize a vault, complete Hello World, preserve exact captured text, and exercise review/gap behavior. They do not test model judgment.
- **Hermes skill discovery:** copied `skills/bodhi-seed/` into a temporary `HERMES_HOME/skills/` and ran `hermes skills list --source local` with installed Hermes Agent v0.21.2. It reported `bodhi-seed` as `enabled`. No model was called and no live Hermes profile was changed.
- **Cleanroom language check:** a Codex Luna max subagent read only the standalone skill and its two references, with no vault or remembered Player One facts. For “Hello, Bodhi,” it produced the seed greeting and a first-win question without claiming existing memory or tools. For a synthetic person wanting more viewers for thrift-flip videos, it proposed a small video experiment and a possible future content calendar; it did not suggest infrastructure from that one request. This is a simulated skill reading, not a Hermes integration test.
- **Observed local-model failure:** in an earlier seeded **vault** run, GPT-OSS-120B saved the synthetic Player One's closing “Yes, that sounds right. Go ahead…” as `priority_verbatim` instead of their earlier substantive goal. The vault accepted it, and restart repeated the wrong priority. The revised `START_HERE.md` now asks for exact goal words, a first useful result, and a readback; `evals/TRIAL.md` scores those points. That revision has not yet been rerun on the local model.
